What it does

Ask the skyType “show me Vega” or “the sky at 9 pm tonight” and the view moves for you.
Guided toursOne click plans a five-stop tour of what is up right now, with narration.
Photo identificationUpload a sky photo and get the objects and constellations named.
Your AI, your keyWorks with any OpenAI-compatible gateway or Anthropic. Keys stay on your machine.

Build it

Nebula is a plugin plus a small patch for Stellarium. On Linux or WSL:

git clone --depth 1 https://github.com/Stellarium/stellarium.git nebula
git clone https://github.com/boysky157/nebula.git nebula-plugin
cd nebula
git apply ../nebula-plugin/nebula-core.patch
cp -r ../nebula-plugin/NebulaAI plugins/
mkdir -p builds/unix && cd builds/unix
cmake ../.. && make -j4
./src/stellarium

Then open the Nebula AI chat window (Ctrl+Shift+N), click Settings, and add your API URL, key and model.
